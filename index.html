합리적 소비의 원리

소비량을 움직이며 한계편익(MB)과 한계비용(MC)을 비교해 보세요. MB = MC에서 총순편익이 최대가 됩니다.
Q = 0
MB > MC → 더 소비
MB = MC → 최적 소비량
MB < MC → 소비 중단

가격 변동에 따른 수요량 변화

가격이 변하면 수요곡선은 이동하지 않고 같은 수요곡선 위에서 수요량이 변합니다.
가격 ↑ → 수요량 ↓
가격 ↓ → 수요량 ↑

가격 변동에 따른 공급량 변화

가격이 변하면 공급곡선은 이동하지 않고 같은 공급곡선 위에서 공급량이 변합니다.
가격 ↑ → 공급량 ↑
가격 ↓ → 공급량 ↓

수요·공급의 변동과 시장균형

수요와 공급이 변동하면 균형가격과 균형거래량이 어떻게 달라지는지 확인해 보세요.
원래 곡선은 실선, 이동한 곡선은 점선
수요곡선: 빨간색 / 공급곡선: 파란색

수요의 변동

가격 이외의 요인이 변하면 수요곡선 자체가 좌우로 이동합니다.
D₀D₁
수요 증가 → 오른쪽 이동
수요 감소 → 왼쪽 이동

공급의 변동

가격 이외의 요인이 변하면 공급곡선 자체가 좌우로 이동합니다.
S₀S₁
공급 증가 → 오른쪽 이동
공급 감소 → 왼쪽 이동

소비자잉여와 생산자잉여

시장가격을 움직이며 소비자잉여와 생산자잉여의 크기가 어떻게 달라지는지 확인해 보세요.
P = 50
수요곡선 아래·가격선 위 → 소비자잉여
가격선 아래·공급곡선 위 → 생산자잉여

가격상한제와 가격하한제

정부가 정한 규제가격과 시장균형가격을 비교하며 초과수요·초과공급을 확인해 보세요.
P = 40
균형가격은 50입니다.
상한가격이 균형가격보다 낮으면 초과수요, 하한가격이 균형가격보다 높으면 초과공급이 발생합니다.

수요의 가격탄력성

수요곡선의 반응 정도와 가격을 움직이며 가격 변화에 대한 수요량의 민감도를 비교해 보세요.
반응계수 = 1.0
P = 50
같은 가격 변화에도 수요량이 크게 변할수록 수요는 더 탄력적입니다.

공급의 가격탄력성

공급곡선의 반응 정도와 가격을 움직이며 가격 변화에 대한 공급량의 민감도를 비교해 보세요.
반응계수 = 1.0
P = 50
같은 가격 변화에도 공급량이 크게 변할수록 공급은 더 탄력적입니다.

조세 부과와 시장균형

단위당 세금을 높여 보면서 소비자가격, 생산자가격, 거래량, 조세수입과 사중손실의 변화를 확인해 보세요.
t = 20
생산자 과세 → 공급곡선 이동
소비자 과세 → 수요곡선 이동
어느 쪽에 법적으로 부과해도 같은 단위세라면 최종 거래량과 경제적 부담은 같습니다.
직사각형 = 정부 조세수입 · 삼각형 = 사중손실

보조금 지급과 시장균형

생산자에게 단위당 보조금을 지급할 때 소비자가격, 생산자가 받는 가격, 거래량과 정부 지출이 어떻게 변하는지 확인해 보세요.
s = 20
생산자 보조금 → 공급곡선 이동
소비자 보조금 → 수요곡선 이동
어느 쪽에 지급해도 같은 단위 보조금이라면 최종 거래량과 경제적 귀착은 같습니다.
정부의 보조금 지출 = 단위당 보조금 × 거래량

외부효과와 사회적 최적

외부효과의 종류와 크기를 바꾸며 시장균형과 사회적으로 바람직한 거래량의 차이를 확인해 보세요.
크기 = 20
부정적 외부효과 → 시장 거래량이 사회적 최적보다 많아짐
긍정적 외부효과 → 시장 거래량이 사회적 최적보다 적어짐
