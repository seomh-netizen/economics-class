합리적 소비의 원리

소비량을 움직이며 한계편익(MB)과 한계비용(MC)을 비교해 보세요. MB = MC에서 총순편익이 최대가 됩니다.
Q = 0
MB > MC → 더 소비
MB = MC → 최적 소비량
MB < MC → 소비 중단

가격 변동에 따른 수요량 변화

가격이 변하면 수요곡선은 이동하지 않고 같은 수요곡선 위에서 수요량이 변합니다.
가격 ↑ → 수요량 ↓
가격 ↓ → 수요량 ↑

가격 변동에 따른 공급량 변화

가격이 변하면 공급곡선은 이동하지 않고 같은 공급곡선 위에서 공급량이 변합니다.
가격 ↑ → 공급량 ↑
가격 ↓ → 공급량 ↓

수요·공급의 변동과 시장균형

수요와 공급이 변동하면 균형가격과 균형거래량이 어떻게 달라지는지 확인해 보세요.
원래 곡선은 실선, 이동한 곡선은 점선
수요곡선: 파란색 / 공급곡선: 빨간색

수요의 변동

가격 이외의 요인이 변하면 수요곡선 자체가 좌우로 이동합니다.
D₀D₁
수요 증가 → 오른쪽 이동
수요 감소 → 왼쪽 이동

공급의 변동

가격 이외의 요인이 변하면 공급곡선 자체가 좌우로 이동합니다.
S₀S₁
공급 증가 → 오른쪽 이동
공급 감소 → 왼쪽 이동
